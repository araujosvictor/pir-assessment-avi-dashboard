Methodology

AVI = total percentage weight of qualifying written coursework / 100. This is a proxy for exposure, not a validated measure of actual AI vulnerability. Zero-credit and unknown-assessment modules have no score. Genuine zero scores are included in averages. Each module code has equal weight; mutually exclusive codes remain separate. Both-semester modules form a separate category. Word-count means exclude unspecified counts; module word totals exclude incomplete modules. Source: Assessments_Complete_with_AVI.xlsx (snapshot).
